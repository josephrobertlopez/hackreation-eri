# Privacy and data rules

1. **Synthetic data only.** Use the files in `data/`. Never type, paste or upload real client info: names, SSNs, case notes, benefits amounts, diagnoses.
2. **No ERI system access.** No logins, exports or screenshots of ERI's real tools.
3. **API keys are yours.** Put them in `.env`, which is git-ignored. Never commit them.
4. **Assume public.** This repo is public. Anything you push is visible to everyone.
5. **Design for real privacy later.** If your idea would hold real data, write down in your team README what it would need: hosting, encryption, consent (ROI), access roles, audit logs. ERI decides after the event.
