# Glossary

| Term | Meaning |
| --- | --- |
| **ADRC** | Aging and Disability Resource Center (county info hubs in WI) |
| **CCS** | Comprehensive Community Services: mental health and substance-use recovery program |
| **CIE** | Competitive Integrated Employment: a regular job, at least minimum wage, alongside non-disabled coworkers |
| **CLTS** | Children's Long-Term Support waiver (WI) |
| **CWIC** | Community Work Incentives Coordinator: certified WIPA benefits counselor |
| **DVR** | Wisconsin Division of Vocational Rehabilitation: funds job services, pays vendors like ERI |
| **EN** | Employment Network: an org (like ERI PLUS) that serves Ticket to Work holders |
| **Family Care / IRIS** | Wisconsin long-term care programs (managed care / self-directed) |
| **IPE** | Individualized Plan for Employment: the DVR plan with the job goal |
| **IRWE** | Impairment-Related Work Expense: disability costs subtracted from earnings when SSA counts income |
| **LTC / LTS** | Long-term care / long-term support |
| **Medicaid / BadgerCare** | Health coverage; often the biggest fear about working |
| **PASS** | Plan to Achieve Self-Support: an SSI rule that lets people set aside money for a work goal |
| **PO** | Purchase order: DVR's written authorization to deliver and bill a service |
| **ROI** | Release of Information: client consent to share records |
| **SE** | Supported Employment: job development plus ongoing on-the-job support |
| **SGA** | Substantial Gainful Activity: SSA's monthly earnings line ($1,690 in 2026 and $1,770 in 2027, non-blind) |
| **SI** | Systematic Instruction: structured on-the-job training |
| **SSA** | Social Security Administration |
| **SSDI** | Social Security Disability Insurance (work-history based) |
| **SSI** | Supplemental Security Income (needs based) |
| **Ticket to Work** | SSA program that pays ENs when beneficiaries work and earn |
| **TWP** | Trial Work Period: 9 months of testing work on SSDI |
| **VFPS** | Vocational Futures Planning and Support: ERI's youth transition model |
| **WIBS** | Work Incentives Benefits Specialist (ERI's title) |
| **WIPA** | Work Incentives Planning and Assistance: SSA-funded benefits counseling; ERI describes itself as WI's sole provider (2021-2026 award; check the current award) |
