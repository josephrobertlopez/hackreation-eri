# Teams

**Most teams don't need this folder.** If you picked a challenge, work inside `challenges/<nn>-.../` on your team branch (see [CONTRIBUTING.md](../CONTRIBUTING.md)). That's where its tests and CI already run.

Use `teams/<team-name>/` **only** if you're building something new from a starter:

1. Make a folder: `teams/<team-name>/` (lowercase, dashes).
2. Copy a starter: `cp -r starters/php-mysql teams/<team-name>/app`
3. Copy `wiki/prds/_template.md` to `teams/<team-name>/PRD.md` and fill in sections 1, 3 and 9 first.
4. Add `teams/<team-name>/README.md` with team members (first names or handles), how to run it, and what ERI would need to adopt it.

Either way: branch `team/<team-name>/<feature>`, and open a pull request before 3:30 (organizers confirm the time). No GitHub access? Ask an organizer, or download your work as a zip from VS Code.
